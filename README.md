# Héritage de Poudlard — Launcher

[Télécharger la dernière version Windows](https://github.com/Immersive-Studio-Corporation/heritage-launcher-distribution/releases/latest)

- **Setup** : installe le launcher et permet ses mises à jour automatiques.
- **Portable** : se lance directement ; remplacer manuellement son EXE pour mettre à jour le launcher.
- Le modpack est synchronisé par le launcher dans les deux cas, avec le contrôle d’accès habituel.

Pour passer des anciennes installations au nouveau canal, installer une fois le Setup 0.1.35 ou une version supérieure.

Ce dépôt public contient les téléchargements et les mises à jour. Les sources sont gérées par la team Developers d’Immersive Studio dans un dépôt privé.
